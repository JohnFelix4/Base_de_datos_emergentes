// 12. Importancia de consultar antes de modificar o eliminar

// Es recomendable ejecutar primero find() utilizando el mismo filtro
// porque permite comprobar exactamente que documentos seran afectados.
// De esta forma se puede verificar el filtro antes de ejecutar una
// operacion que modifique o elimine documentos.

// 13. Diferencia entre matchedCount y modifiedCount

// matchedCount indica cuantos documentos coincidieron con el filtro.
// modifiedCount indica cuantos documentos realmente fueron modificados.
// Un documento puede coincidir con el filtro pero no necesitar cambios,
// por lo que matchedCount puede ser mayor que modifiedCount.

// 14. Ventaja de utilizar $addToSet

// $addToSet agrega un elemento a un array solamente si ese elemento
// no existe previamente.
// Esto evita valores duplicados dentro del array.
// Por eso es mas adecuado que $push cuando se desea evitar duplicados.
