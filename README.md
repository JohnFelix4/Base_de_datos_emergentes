# Base_de_datos_emergentes
## Prácticas

* **Práctica 1 — Introducción a MongoDB:** Creación de bases de datos y consultas, avanzando hacia grandes volúmenes de datos para estudiar rendimiento, índices e integración con Python.

* **Práctica 2 — CRUD y control de cambios:** Aplicación de operaciones de inserción, lectura, actualización y eliminación mediante filtros seguros.

* **Práctica 3 — Operadores, arrays y condiciones combinadas:** Construcción de consultas con operadores de comparación, lógicos, existencia y arrays.

* **Práctica 4 — Proyección, ordenamiento y paginación:** Control de campos, ordenamiento y paginación de resultados mediante `skip()` y `limit()`.

* **Práctica 5 — Modelado documental:** Aplicación de las estrategias de *embedding* y *referencing* para representar relaciones entre documentos.

* **Práctica 6 — Aggregation Pipeline I:** Uso del framework de agregación para filtrar, agrupar, resumir y ordenar información de ventas.

* **Práctica 7 — Aggregation Pipeline II:** Aplicación de etapas avanzadas de agregación para transformar campos, trabajar con arrays y analizar información temporal.
